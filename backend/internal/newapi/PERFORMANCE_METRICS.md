# 模型性能统计

参考 New API 固定基线 `48f9df96ea7c68eae04a0f3687869f232f48929f` 的 `pkg/perf_metrics/outcome.go`、最终 relay / Task 边界。本站沿用 Go/Gin、既有模型分组权限和 PostgreSQL 查询方式；不直接移植无界 hot bucket 或每样本 goroutine。

## 最终来源

- HTTP Chat / Responses / Messages、Gemini generateContent/streamGenerateContent 在同步 Forward 返回时只保存不可变计数和时钟；外层请求结束后采样一次。尝试失败后恢复成功只算最终一次。零价和用量日志写入失败不改变最终结果。
- HTTP 200 不等于成功。Forward 错误、截断或终态 SSE 错误优先于部分用量；本地业务限制、已识别的输入/审核拒绝、未完成时取消不进入分母。代理在正常完成后才取消不会抹掉成功。凭据、上游限流和容量错误仍按失败处理。
- 视频使用插件和旧原生持久表的首次生成终态，统计创建到本站观察终态的完整耗时；不依赖提交 HTTP 时间或用量日志。重复查询、补交付和结算不新增样本。失败与交付/账务状态保持分离。
- Responses WebSocket 多轮（ctx-pool/dedicated/passthrough、WS→HTTP 桥）按每轮客户端公开模型、连接所属分组和实际目标平台独立采样。HTTP 请求使用 WS 上游仍在 HTTP 最终请求边界只算一次；不把一整条长连接算成一个生成。隐藏的同账号重试/换号恢复只保留最终结果，尝试都失败才记一次失败，完成后的空闲或关闭不凭空增加一轮。
- WS 终态沿用固定 New API 的结果语义：completed/done 为成功，incomplete 的 max_tokens/max_output_tokens 为成功，未知 incomplete/上游失败为失败，内容审核/已识别输入拒绝/取消排除。HTTP 200、已计量部分用量、正常关闭握手都不能代替终态证据。上下游方向分开判断，生成途中上游以 1000 关闭仍是缺少终态，客户端中断后的有界用量排空不造成功。
- passthrough 沿用原先的写出前计费回调，另加终态写出后才执行的纯统计回调；写出失败或已经进入客户端断开排空的终态不计样本。裸 error→response.failed 只算一次，等待权威终态时新接受的下一轮单独保留。JSON 二进制终态可作健康观察，仍保留原先不从二进制帧提取用量的约定，不猜输出 Token 或 TPS。
- 同步 Images、Embeddings 与 Grok Voice TTS/STT 已在实际下游 HTTP 边界独立采样。图片必须观察到真实图片输出，流式还需明确终态；计费兜底图片数量不是成功证据。Embeddings 必须有非空向量/编码，TTS/STT 按实际音频/转录结果判断。下游错误/短写排除，不把媒体字节、图片推理 Token 当文本 TPS。
- Grok Realtime 和 OpenAI Live 按 `response.created` 到明确终态逐轮采样，复用同一 recorder；成功握手、SDP、session.closed 或整条连接耗时不作为生成成功。Realtime 已确认上游中断时，将已开始但未完成轮次记失败；客户端断开不算上游失败。Live 控制连接中断不能证明独立 WebRTC 媒体失败，不补造样本。Live 旧缓存缺少公开模型身份时不采样。
- 媒体 WS 每连接最多保存 8 个在途响应 ID（各最多 128 字节）和时钟，不保留音频/转录/凭据。Live 观察器与实际 sideband 使用会话/响应的稳定 UUID，重连重放由数据库防重；尚未接入 Provider/Transform 的 WS hooks。
- 迁移 265 固定一次 cutover 时间。已迁移 HTTP 端点在 cutover 后只读独立样本；即使遥测缺失，也不把部分用量回填成成功。升级前及未迁移协议继续读旧日志。滚动部署期间旧实例尚未提供独立样本，可能出现短暂缺口；不伪造历史补齐。
- 迁移 279/280 分别固定 media_http_started_at 与 media_ws_started_at；切换后同步媒体和 Realtime/Live 不再由部分用量或整会话日志回填成功，原历史保留。重复迁移不会重置分界。
- 迁移 271 单独固定 websocket_started_at，不改原 HTTP 分界。新分界后 request_type=3 或旧 WS 标记的用量不再兜底为成功，对应运维日志也不重复累计；缺少入站端点的旧 WS 日志同样按新分界处理。升级前 WS 历史和未迁移的其他协议保留，重复迁移不重置任一分界。

## 资源、耐久和金额边界

- 一个固定 worker、1024 队列、最多 128 条在途，每条只保留 UUID、分组/平台/模型和数值。不保存 Gin context、账号、凭据、正文、响应或上游错误文案。模型最多 100 UTF-8 字节、平台 32 字节。
- WS 每连接使用一个当前轮次和最多一个已接受后继槽位，互斥保护读/转发回调，最多两份 100 字节公开模型、时钟和枚举。失败等待换号时不保留异常对象或正文。它复用同一有界 recorder，不新增逐轮 goroutine、历史 map 或计费队列。
- 正常最多约一秒批量落库；满批立即写。一次写最多两秒、最多两次；同一 UUID 重试 `ON CONFLICT DO NOTHING`，避免不确定确认重复插入。关闭先停止接收，五秒内排空，截止后取消数据库操作并计丢弃。
- 与 New API 的内存采样一样，这不是财务 outbox。进程崩溃、队列满或数据库持续失败可能丢遥测；有累计 accepted/persisted/dropped 计数和节流系统告警，不能宣称零丢失。不会为了指标回滚账务或让已成功的生成重试。
- 样本保留 48 小时，每十秒有界删除最多 5000 条，单次一秒预算；持续高于清理能力时保留可能滞后。普通公开统计只读近 24 小时，完全不修改账务保留。
- TTFT 对齐整次请求时钟；速度使用总输出 Token / 总有效生成时长，未知首字时间不猜 TPS。P95 直接对原样本求值，不平均小时/分组分位数。
- PostgreSQL 多实例共同读取同一来源，仍按模型、平台、可见分组的精确组合隔离。指标独立于 Ops 开关，但现有 Ops 关闭和日志过滤的行为保留。

本批验证覆盖独立临时 PostgreSQL 的新/重复迁移、日志关闭/删除后独立结果、同样本重复写、原生终态和重复查询、权限 scope、部分用量不回填、保留清理；竞态覆盖有界队列、失败重试、快照所有权、关闭与取消。已接当前这些入口的最终采样；实际平台付费联调仍待执行，不能推及未来新增协议或未接入的插件 WS hooks。

## 页面更新通知

`GET /api/v1/model-plaza/performance/updates?group_id=…&ids=mdl_…` 为受现有 OptionalJWT、后台模式和面板限流保护的短 SSE。仅支持一个明确可见分组、当前页最多 24 个模型；单实例最多 16 个连接，超限 503 + Retry-After，不建立等待队列。每个连接最长 20 秒，每两秒复核 JWT 到期、当前用户启用/TokenVersion/角色、广场开关、分组/模型权限。连接重建重新经过完整鉴权及会话绑定。当前访问令牌的会话撤销语义沿用原 JWT 中间件；不是另一套认证协议。

通知正文只有空对象，事件为 ready / refresh / scope_changed，不携带指标、任务、用户名或私有模型名。每次检查通过有索引的最多 24 个精确 scope 读取最新样本/视频终态标记，不重新计算全量 P95；不在共享锁中查库。读版本最多一秒、权限检查最多两秒，逐次写/flush 截止三秒，传输不支持写截止时拒绝 SSE。服务 Shutdown 主动取消连接。多实例读共同数据库，无单进程通知缓存或跨租户全局广播。

前端用 fetch 携带 Authorization header，令牌不放 URL；限制单事件 1 KiB、连接 16 KiB/64 帧、28 秒总预算。切分组/翻页/隐藏/卸载取消旧 reader；回到页面重取，失败退避，普通 15 秒请求仍负责兼容降级、历史日志与窗口过期变化。scope_changed 清空旧展示并走普通权限接口重取，不能继续显示旧缓存。HTTP/Responses WS 与媒体的新独立样本通常在约一秒落库及下一次两秒检查后更新；不是零延迟保证，其他旧日志来源仍以常规刷新为准。
