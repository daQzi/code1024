# 外部插件市场

管理员在「插件中心 → 插件市场 → 外部市场」读取 New API `indexVersion: 1` 索引。默认包含 New API 官方站、GitHub 原始文件镜像和 New API 社区源；本站社区投稿仍使用原有草稿、审核、发布流程。

市场来源使用现有 `settings` 表中的 `plugin_marketplace_sources` 配置，不增加第二套插件库或数据库迁移。`GET/PUT /api/v1/admin/newapi-plugins/marketplace/sources` 读取和修改来源；写入复用管理员二次验证。最多 16 项，名称最多 120 字节，索引地址最多 2048 字节，只接受无凭据、查询参数和片段的 HTTP(S) 绝对地址。显式保存空列表会关闭外部来源，不自动恢复默认项。

浏览器直接下载索引与文件，服务器不代理任意市场 URL。来源需要允许浏览器跨域读取，HTTP 来源还受浏览器的混合内容策略约束。来源标签由固定地址决定，索引或管理员填写的名称不能让自定义源显示为官方。公开市场的可访问性不属于宿主兼容验收；当前开发环境读取公开索引遇到 HTTP 403，回归使用虚构索引与源码。

## 安装路径

1. 索引提供插件名称、公开模型、推荐顺序、作者、版本、类型、SHA256、声明的允许主机及使用文档。支持 Task、Provider、Transform；缺少摘要的版本可以展示，但不能从市场安装。未知类型过滤，重复 key/版本及不支持的索引版本拒绝。索引声明不替代脚本编译结果和宿主能力检查。
2. 查看版本时下载 `plugin.js`，校验完整 UTF-8 源码 SHA256；保留 BOM，不重写换行或源码。使用说明、变更记录支持索引声明的语言文件，以纯文本显示，存在文档摘要时同样校验。没有远程图标、HTML 执行或自动加载外链图片。
3. 点击安装进入既有管理员二次验证。每次实际执行安装动作前重新读取索引，确认固定 key/版本/摘要仍存在、未撤回且 `minApiVersion <= 1`，然后重新下载并校验源码。旧下载或旧选择不能覆盖新版本的状态，关闭或离开取消读取。
4. 管理 API 接受 `{source, allow_builtin_override, marketplace: {index_url, key, version, sha256}}`。服务端核对来源仍在配置列表中，在执行 JS 之前计算并核对 SHA256，编译后核对实际 key/版本；系统 key 覆盖继续要求原有明确选项。来源持久记录为 `market:<official|community|third_party>:<index_url>`。
5. 安装不自动启用或切换已有账号的固定版本；返回实际宿主兼容报告。原版本、在途任务、当前启停状态遵循既有不可变版本规则。市场撤回只阻止市场新安装，不擅自取消已接受任务或停用管理员已安装版本。

来源索引和撤回检查在浏览器中完成，服务端验证的是管理员提交的源码与固定摘要/身份，而不是来源的数字签名证明。拥有源码上传权限的管理员仍能通过原上传入口安装代码；界面来源标签不能作为代码可信或完整能力兼容的证明。本集成不发送网关身份或市场安装遥测。

## 系统与已安装版本源码审阅

插件中心的详情增加“查看源码与版本对比”。系统工厂可在安装前查看；已安装插件可查看固定版本，并选择同一 key 的历史版本作为基准，展示旧/新行号及新增/删除行。原始源码使用只读文本框完整展示，不执行脚本或渲染源码中的 HTML；大源码超过对比限制时仍可查看和复制全文。查看与比较不会更改默认版本或账号绑定。

- 管理 API：`GET /admin/newapi-plugins/versions/:id/source` 和 `GET /admin/newapi-plugins/factories/:key/source`，沿用现有管理员鉴权。没有新增受限管理 Key 权限；只有完整管理权限可以读这些未单独授权的端点，未登录/其他只读权限不能借此取源码。
- 返回固定 key、版本、SHA256、原始源码及已安装 ID，没有运行状态、账号连接、已保存配置或凭据对象。源码本身是管理员请求审阅的完整注册表工件。服务端及浏览器独立核验 SHA256，保留 BOM、CRLF 和 Unicode 原始 UTF-8；未知 ID、损坏摘要、非 UTF-8、超过 1 MiB 均拒绝。该校验不证明代码行为可信。
- 服务端先从已有共享 64 MiB 管理请求预算预留 16 MiB（账面准入，不是 RSS 限额），覆盖源码/DB 投影和最坏 JSON 转义，再读取 DB/源码并序列化；DB 查询最多 5 秒，客户端取消传到查询，结束归还准入。返回 `private, no-store` 与 `nosniff`。不创建后台队列、网络请求或文件写入，不执行上传/社区脚本；工厂元信息沿用启动登记的受信内置目录。
- 浏览器仅在展开时取所选版本，比较时最多保留当前/基准两份源码；关闭、换插件或版本、卸载取消在途读取，旧响应不能覆盖新选择。逐行算法参考固定 New API 基线，提前限制每侧 65536 个 UTF-16 单元、1500 行；平面 Uint16 LCS 表最多约 4.51 MB，渲染最多 3000 行，避免原无限二维矩阵的资源放大。
- 这是系统/已安装 JS 版本的源码审阅，不包含原生 `.s2plugin` 解包或在线执行。New API 基线的 code resolve 是 8 位社区编号查询；当前已接入编号查找及目录条目合并，不自动合并 JS 源码。外部市场仍走前文的固定摘要安装流程。

## 市场候选与本站安装版本比较

外部市场版本下载完成后，如果本站已安装同 key 的插件，可以展开“与已安装版本比较”。比较复用上述源码端点与有界逐行算法；默认以本站版本列表中的首个同 key 版本为基准，也可选择其他已安装版本。候选源码直接使用当前已经下载的固定市场工件，不额外读取系统工厂或运行脚本。

- 比较前再次核对两边的 key、版本、原始 UTF-8 SHA256 与大小，本站工件还核对安装 ID。候选改变、关闭、切换或卸载取消本站源码读取；版本列表更新后重新读取基准，旧响应不能覆盖当前候选。
- 远程源码在原市场详情完整只读展示，比较区域仅展示差异，沿用每侧 64 KiB UTF-16 单元/1500 行限制。不自动合并代码、不安装或启用，也不在候选之间保留源码缓存。
- 后续点击安装仍重新检查索引、撤回和摘要、重新下载源码，再走管理员二次验证与固定版本安装；查看差异不代替安装时校验。

回归覆盖真实 Vue 组件中的候选下载、本地读取、两端摘要核对、版本元信息刷新与手动固定 pin 安装，不代表公开市场网络已验收。

## 资源与取消

- 每次读取总截止时间 20 秒，覆盖响应正文消费；`credentials: omit`、`redirect: error`、`cache: no-store`、`referrerPolicy: no-referrer`。
- 索引最多 2 MiB、2000 个条目，每插件最多 100 个版本；源码最多 1 MiB；每个文档最多 64 KiB；列表每页 24 个。
- 版本文件和文档必须与索引同源。来源重定向拒绝，不把跨域目标当作原来源。
- 使用固定上限字节缓冲，逐块检查实际字节数；无 `Content-Length` 也受限。完成、超限、异常、取消时取消流并释放 reader 与定时器。页面只保留当前索引和当前版本，不缓存全部源码。
- 服务端安装继续使用已有共享请求内存准入、1 MiB 源码限制及固定 JS worker；没有新增后台任务或计费链路。

验证包含浏览器传输模拟的大小限制、截止时间、取消、BOM/UTF-8 与摘要；真实 Vue 组件的版本切换、撤回、安装参数、二次验证和来源管理；Go 实际 JS 子进程的固定名称/版本、系统覆盖保护和摘要检查早于脚本执行。它们不代表真实上游模型或公开市场网络已验收。

## 按编号查找

外部市场新增 8 位数字编号查找。先按官方优先读取已配置来源索引；未列出的社区插件再向已配置的固定 New API 社区 `resolve?code=…` 查询。管理员移除社区来源后不会访问它。第三方来源按已配置索引搜索，不猜测其私有查询协议。

- 浏览器自行请求，原大小、UTF-8、禁重定向、无凭据和取消限制保持一致；来源顺序读取，整体最多 45 秒。查询参数仅在固定社区解析地址由 8 位数字生成，不放宽索引和源码地址规则。
- resolver 必须返回唯一且编号一致的插件；结果单独标明来源，源码和文档按该来源地址解析。查找不保存配置、不安装或启用。
- 合并指目录条目合并，同 key 整条替换，不混用两份版本文件和摘要，保留当前索引与 resolver 的全部撤回记录；不自动改写 JS 源码。
- 真正安装在二次验证后重新读取该来源索引和该编号 resolver；删除、改摘要、撤回均阻断。随后重新下载和核验源码，再交给原固定版本安装。
- 换来源、刷新、返回和离开取消旧查找，旧响应不能覆盖新列表。32 项工具、Vue、源码比较和 i18n 测试通过，TypeScript 与受影响文件 ESLint 通过。公开网络和真实上游验证仍待 R8 验收。
