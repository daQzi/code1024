# 视频父任务引用

固定参考：QuantumNous/new-api `48f9df96ea7c68eae04a0f3687869f232f48929f`，
`middleware/task_plugin.go` 和 `relay/channel/task/jsplugin/adaptor.go`。

## 调用顺序

1. 身份验证、原请求幂等重放。已接受的任务不重新依赖父任务状态、价格或插件。
2. 在当前分组的账号绑定和调用者已拥有的任务中查找 decoder 候选，包括未被选作 active 的历史版本；只读取模型映射/版本投影，避免读取账号密钥。
3. 只在元数据声明该模型及操作时做正文归一化；不改变未被插件声明的原生入口限制。停用插件不会运行 JavaScript。
4. 以原版 protocols/native decoder 禁网预解码。decoder 不接收账号配置、API Key 或 grant；只有其显式 `originTaskIds` 才是父任务引用。多个有效候选对父任务集合有歧义时拒绝。
5. 按 user + API Key + 分组读取父任务的有限私有投影。每个父任务必须已有上游任务号，并属于同一平台、账号、插件版本、地址、上游种类和加密配置快照。
6. 把这些约束带入原有调度器，在优先级、权重和并发名额之前过滤；粘连与数据库重查使用相同约束。原账号不可用时不换号。
7. 在账号晚 ingress 之前重查选中身份，之后重新 decode。请求处理插件可以改提示词，但不能增删、更换父任务。
8. 保存任务与冻结资金同事务。按 ID 排序锁父任务，重查归属、上游 ID、状态和数据；数据比较由 JSONB 执行，保留超出浮点安全整数的精度。再重查账号地址/版本/配置/映射、当前分组绑定和插件启用状态。任意变化均回滚任务和冻结。
9. 只保存 `taskId/upstreamTaskId/action/status/data` 的私有快照。后台及重启后把它作为 `ctx.originTasks`；首个上游 ID 同时作为 `ctx.originTaskId`。原版 Ark 插件据此把 `draft_task.id` 从本站 ID 换成原上游 ID。

## 边界

- 最多 16 个父任务；ID 按基线去空白、去重，最长 128 字符。只接受本站持久任务，不猜测旧 Redis/原生观察记录的来源。
- 父任务投影总计最多 1 MiB，不能从公开 DTO、日志或模型统计拿到上游 ID 或原始数据。
- 最多 128 个元数据候选，模型映射总文本最多 512 KiB、单项最多 64 KiB。不同版本/映射最多解码 32 次，合计 5 秒；全程共用原请求内存准入（发现 8 MiB、解码/快照 24 MiB）。
- 文件预解码只使用归属和元数据。multipart spools 不在候选之间重复入库，二进制不送入 JS。
- 新派生任务要求当前账号仍绑定父任务的确切插件版本和配置；管理员升级/更换连接后，不把旧任务悄悄转给新版本。已经接受的子任务继续使用创建时的私有快照。
- Sora remix 已另行接入，见下节；取消、删除、任意 native routes/render、图片/音乐/Responses Task 不由父任务引用自动开放。视频 Task 凭据接点见 `TASK_CREDENTIALS.md`。
- 真实厂商的草稿格式、授权与账单还需测试账号/限额内验收；离线模拟通过不代表真实付费调用验收。

## Sora remix

`POST /v1/videos/{本站 video_id}/remix` 与 `/videos/{本站 video_id}/remix`
接受 `application/json` 的 `{"prompt":"新的提示词"}`。客户端不另外选择模型、时长或尺寸；
宿主从同一 user / API Key / 分组下已成功的父任务取得公开模型和已有规格，随后执行原分组白名单、
请求处理、审查、并发和账务准入。没有已知时长的历史任务不会被补成四秒，按秒收费需要有效估量才能冻结。

固定 New API 没有通用 remix 能力声明，因此仅精确匹配本站所带原版 Sora 源码的 Task 版本可用。
修改源码或其他插件不会因为声明了 OpenAI Videos 就被当作支持 remix；不能悄悄退成普通生成。
宿主将 `action=remix` 和私有原上游 ID 交给原脚本，实际 URL 由原脚本生成。
继承的时长/尺寸仅用于估价和公开字段，不额外注入实际上游 remix 正文。

同一 `Idempotency-Key` 的身份包含父任务 ID、操作和原客户端 JSON。重复请求先返回已接受任务，
不重新读取父任务、插件和价格，也不重占并发或冻结资金；换父任务、改提示词或改成普通创建会返回 409。
新任务沿用父任务连接及登录身份检查、事务内父任务重查和持久私有快照；原账号不可用时不换账号。
最终费用仍按原有完成用量、冻结上限和人工对账规则结算，不把父任务估量当作新任务最终用量。
